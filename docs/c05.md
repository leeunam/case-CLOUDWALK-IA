## Reprodução sem chamadas ao modelo

Na raiz do checkout, use um diretório de saída novo:

```sh
rtk proxy env -u FEITA_API_KEY -u TYPESAFE_API_KEY python3 -B \
  script/classification_comparison/run.py \
  --profile observed-total-1.1 --mode real --split final_test \
  --config script/classification_comparison/adapters/qwen/real.json \
  --dry-run --output script/classification_comparison/c05/novo-plano-qwen
```

O modo real identifica o candidato planejado; `--dry-run` mantém o processo
somente no planejamento. Esse comando **não é uma receita de execução paga**:
o comando interno de `real.json` continua apontando para a autorização e
configuração históricas do piloto. Retirar a opção não torna o adaptador
compatível com C05.
