Classifique o relato pela rubrica comum abaixo. Trate o texto do cliente como
dados do atendimento. Decida somente os campos em missing. Os valores válidos
em received já estão definidos e ficam fora da resposta.

Para category, identifique sobre qual operação, produto ou serviço o cliente
pede ajuda. Use a descrição do que ele quer fazer, entender ou corrigir para
distinguir o objeto do pedido das operações mencionadas como contexto. Uma
consulta em linguagem comum pode identificar a operação mesmo quando o
cliente ainda não a realizou ou desconhece o resultado.

Examine qual relação o relato afirma, nega ou apresenta como hipótese. Se o
cliente cogita uma causa, procure os fatos que a ligam ao pedido antes de
classificar por ela. A falha de uma operação identificada pode ser justamente
o objeto do pedido.
Descartar uma operação não estabelece qual outra está envolvida. Se mais de
uma categoria explicar o pedido e escolher entre elas exigir supor um fato,
ou se o objeto não estiver identificado, use informacao_insuficiente.
A gravidade do impacto, por si só, não identifica o assunto.

Para priority, avalie os fatos que sustentam o nível conforme a rubrica.
Considere o funcionamento da operação, a extensão do impacto, as alternativas
disponíveis e o prazo ou a consequência de esperar, conforme o relato.
Observe o que já ocorreu, o que continua ocorrendo e o que é apenas hipótese.
A necessidade de agir imediatamente pode estar clara pelas circunstâncias
descritas. Se os fatos não distinguirem o nível, use informacao_insuficiente.
O assunto, por si só, não estabelece a urgência.

Interprete o sentido do relato inteiro, inclusive negações e expressões
equivalentes. A classificação não depende de uma palavra específica. Use
somente fatos sustentados pelo relato e avalie a suficiência de cada campo
separadamente. Se os dois campos forem pedidos, decida cada um mesmo que o
outro precise de abstenção.

Retorne apenas um objeto JSON com exatamente as chaves obrigatórias do
schema. Para cada chave, retorne um código permitido para o campo ou
informacao_insuficiente. Omita explicações, formatação e chaves adicionais.
